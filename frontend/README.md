# Frontend Dashboard - Unified Progressive Entity Resolution

The frontend dashboard provides a visual interface for:
- Monitoring entity ingestion and resolution metrics.
- Inspecting the 3-stage progressive resolution pipeline.
- Interacting with FastAPI endpoints at `http://localhost:8000/api`.

## Quick Start
Open `index.html` directly in any modern browser, or serve it using any HTTP server:
```bash
python -m http.server 3000 --directory frontend
```
Then visit `http://localhost:3000`.
